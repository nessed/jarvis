# enum that depends on `_missing_` being reached; CPython added a guard that

# 3.11.5. Do not "upgrade" it. See docs/blockers/pyflp-python-312.md.
#
# Recreate:
#   py -3.11 -m venv --clear .venv311
#   .venv311\Scripts\python.exe -m pip install -r requirements-flp.txt
#
# Run the tests:
#   .venv311\Scripts\python.exe -m pytest -q -m realflp tests/flp -p no:cacheprovider --basetemp=.pytest-basetemp
#
# Keep this list at two direct dependencies. If a third is ever needed, that is
# a signal to move the whole project to 3.11, not to widen the sandbox.
