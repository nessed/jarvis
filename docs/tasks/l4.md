# L4 — new provider live smoke tests

## Ownership

No repository code ownership. Do not edit project files or commit. Report the
result to the orchestrator, who updates `docs/context.md`. Do not reveal keys,
tokens, or request headers that contain credentials.

## Preconditions

The user has completed the batched OpenRouter, NVIDIA NIM, and Mistral console
key creation and each corresponding local `.env` variable is present.

## Objective

Run one minimal, non-billable/free-tier-safe request through each new configured
rung. Confirm a 200-class result and that the router records available
rate-limit/retry headers dynamically rather than relying on static limits.
Use official current documentation to validate endpoint/model configuration;
do not assume a roster or a free-model ID. Report safe per-provider pass/fail
and any configuration correction needed.
